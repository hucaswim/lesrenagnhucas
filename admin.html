Pelacakan Pengunjung

Tempel ID di bawah, Download data.js, lalu upload ulang. Kosongkan kolom yang tidak dipakai. Kalau keduanya kosong, tidak ada pelacak dan tidak ada banner cookie. Pelacak hanya aktif setelah pengunjung menekan Terima pada banner cookie, dan data pribadi (nama, nomor WA) tidak dikirim ke pelacak.

Cara dapat: analytics.google.com → Admin → Create property → Data streams → Web → isi alamat website → salin Measurement ID (diawali G-).
Cara dapat: business.facebook.com → Events Manager → Connect data sources → Web → Meta Pixel → salin Pixel ID (angka saja).

Event yang tercatat otomatis

  • Kunjungan halaman (website & artikel)
  • Lead — form booking dikirim (hanya jenis kelas & lokasi, tanpa nama/nomor)
  • Klik WhatsApp — tombol/link WhatsApp ditekan

Tes: buka website, tekan Terima di banner, lalu cek Realtime di Google Analytics dan Test events di Meta Events Manager. Laporan lengkap di GA/Meta butuh beberapa jam untuk muncul.

Testimoni

Bagian Testimoni di website tersembunyi sampai ada minimal satu testimoni. Hanya masukkan testimoni asli dan minta izin pemberi testimoni dulu (terutama orang tua murid anak) — cukup nama depan atau inisial untuk menjaga privasi anak.

Gambar Website

Gambar yang di-upload otomatis diperkecil & dikompres supaya website tetap ringan. Foto coach diatur di tab Coach, gambar artikel di tab Blog.

Gambar utama (Hero) — foto kolam / kelas renang

Tampil di bagian paling atas website, di samping judul. Disarankan foto landscape (rasio ±4:3), minimal lebar 1000px. Kalau dikosongkan, website memakai ilustrasi kolam bawaan.

Gambar preview saat link dibagikan (Open Graph)

Gambar yang muncul saat link website dibagikan di WhatsApp/Instagram/Facebook. Harus berupa URL lengkap (https://...) ke file gambar yang sudah kamu upload ke hosting, ukuran ideal 1200×630px. Contoh: https://domainkamu.com/og-image.jpg

Pengaturan SEO

SEO = supaya website HUCAS muncul saat orang mencari "les renang bali", "les renang denpasar", dll di Google.

Tanpa garis miring di akhir. Dipakai untuk canonical URL, sitemap.xml, dan data terstruktur Google.

File SEO otomatis

Catatan: sejak website memakai halaman statis, sitemap.xml, robots.txt, tag SEO, dan data terstruktur dibuat otomatis saat website dibangun. Tombol di bawah tidak perlu dipakai lagi.

Klik, lalu upload file hasil download ke folder yang sama dengan index.html di hosting.

Salin kode ini lalu tempel menggantikan blok antara <!-- SEO:START --> dan <!-- SEO:END --> di index.html. Ini penting supaya preview WhatsApp/Facebook memakai judul & gambar yang benar (mereka tidak menjalankan JavaScript).

Checklist SEO setelah website online

  1. Isi alamat website di atas, lalu download sitemap.xml & robots.txt dan upload.
  2. Daftarkan website di Google Search Console, lalu kirim sitemap.xml.
  3. Buat Google Business Profile untuk HUCAS (penting untuk pencarian lokal "les renang dekat saya") — cantumkan lokasi Renon/Ubung/Padang Sambian.
  4. Tulis artikel rutin di tab Blog (judul memuat kata kunci, 300+ kata, isi pertanyaan yang sering dicari orang tua).
  5. Pasang link website di bio Instagram @hucasswimmingclass.
  6. Pakai gambar asli kelas HUCAS (bukan stok) dan isi nama file gambar yang deskriptif.
